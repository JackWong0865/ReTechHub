# ReTech Hub

ReTech Hub is a web-based platform that provides an integrated marketplace for second-hand electronic devices together 
with repair booking services. The system allows users to purchase quality second-hand products, request repair services, 
and track their repair status through a single platform.

This project was developed as a Final Year Project for the Diploma in Information Technology.

---

## Features

### User
- User Registration & Login
- Email OTP Verification
- Browse Second-hand Electronic Products
- Search & Filter Products
- Shopping Cart
- Checkout & Order Placement
- Order History
- Repair Booking
- Sell Device Request
- Repair Status Tracking
- User Profile Management
- In-system Notifications
- Chat with Admin

### Admin
- Dashboard
- User Management
- Product Management
- Upload & Edit Products
- Draft Product Management
- Order Management
- Repair Booking Management
- Sell Request Management

### Technician

- Update Repair Status

- View Booking Details

## Installation

1. Clone this repository

```bash
git clone https://github.com/yourusername/retech-hub.git
```

2. Move the project folder into the XAMPP `htdocs` directory.

3. Import the SQL database into phpMyAdmin.

4. Configure the database connection in:

```
includes/db.php
```

5. Start Apache and MySQL using XAMPP.

6. Open your browser:

```
http://localhost/retech-hub
```
